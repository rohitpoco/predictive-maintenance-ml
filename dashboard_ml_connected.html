How the prediction works

This front end scores each reading against normal and critical limits (for example, vibration bands follow ISO 10816-style severity zones). Each reading becomes a stress value from 0 (normal) to 1 (critical). A logistic model combines the weighted stresses, the single worst reading, and a few interactions such as heat plus vibration to give the probability of failure in the next 14 days.

The weights and limits are engineering defaults for demonstration. They are not trained on your fleet. To use a trained model (Random Forest, XGBoost, LSTM and so on), replace the predict() function in the page source with a call to your own API that receives the payload below and returns the same fields: probability, failure causes and ordered actions.
